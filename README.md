# To-Do List

A to-do list web app written in plain HTML, CSS and JavaScript.

## Features

- Add tasks, mark them as done and delete completed tasks
- Filter the list: all, active or completed tasks
- Counter of the remaining tasks
- Light and dark mode
- Tasks, the selected filter and the colour mode are saved in the browser's `localStorage`, so they are still there after a reload

## Running

Open `index.html` in a browser.
